1 · Add clothes

PNGs only, on the same canvas as aloo.png. Pick the category and name for each, then press Add. Using a file name that already exists in that category replaces the artwork.

2 · The carousel

Items are grouped under the tabs players see. Use the arrows to reorder items of the same type, rename them, or change an item's type (which can move it to another tab).

3 · Put it on GitHub

Everything you've changed is collected in a folder called to-upload. Just drag what's inside it onto GitHub.
